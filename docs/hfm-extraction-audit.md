# Public-release boundary

HFM Parity Lab is an independent implementation of a general trace-parity
approach. It does not include code, data, numerical aggregates, model artifacts,
or internal reports from another system.

## Included

- A versioned JSONL trace format.
- A standalone Python standard-library recorder.
- Pure alignment and comparison logic.
- Synthetic fixtures and adversarial tests.
- A static report viewer.

## Intentionally excluded

- Source market data and derivatives.
- Production configurations, calibrations, and model artifacts.
- Personal, absolute, or internal paths.
- Results without established redistribution rights and provenance.

Public fixtures therefore cannot independently prove any historical measurement.
They are reproducible test cases for the API and report format only.
